Carga masiva

Importar jugadores

Selecciona un archivo CSV de Excel. Primero se validará y luego podrás confirmar la importación. Solo necesitas las columnas nombres, apellidos y curso. El sistema reconoce automáticamente archivos separados por coma o punto y coma y calcula el grupo de competencia a partir del curso.

Columnas requeridas: nombres,apellidos,curso

El grupo no se incluye: INVICTUS lo calcula automáticamente. El ID tampoco se incluye; el sistema lo genera.

Sorteo automático

Sortear partidos

Selecciona la disciplina. INVICTUS organiza los equipos por categoría y genera ida y vuelta; en videojuegos forma las parejas automáticamente.

Selecciona una disciplina para ver los grupos disponibles.
